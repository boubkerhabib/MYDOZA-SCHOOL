# 🎓 MYDOZA SCHOOL

### Plateforme éducative en ligne

MYDOZA SCHOOL est une plateforme éducative en ligne qui a pour objectif de faciliter l'apprentissage des élèves grâce à des cours, des leçons, des exercices et des examens accessibles en ligne.

Le projet vise à offrir une expérience d'apprentissage moderne, simple et intuitive.

## 📌 Présentation du projet

Le développement de MYDOZA SCHOOL est divisé en deux parties principales :

- **Backend :** Développé avec l'aide de l'intelligence artificielle (IA).
- **Frontend :** En cours de développement avec HTML, CSS et JavaScript (Vanilla JS).

## 🛠️ Technologies utilisées

### Backend
- Node.js
- Express.js
- REST API
- JSON
- JWT Authentication

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Fonctionnalités prévues

- Inscription et connexion des utilisateurs.
- Gestion des élèves et des enseignants.
- Consultation des cours et des leçons.
- Gestion des matières scolaires.
- Examens et évaluations en ligne.
- Suivi de la progression des élèves.
- Gestion des certificats.
- Tableau de bord personnalisé.
- Gestion des abonnements.
